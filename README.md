# 📊 EDA using Matplotlib

Welcome to the **EDA using Matplotlib** repository! This project showcases a variety of exploratory data analysis (EDA) visualizations created using Python's powerful **Matplotlib** library.

## 🔍 Overview

This repository demonstrates different types of graphs that help explore and understand relationships within data. It is useful for beginners learning data visualization as well as for quick reference in data analysis projects.

## 🛠 Requirements

- Python 3.x
- Matplotlib
- Pandas
- Seaborn
